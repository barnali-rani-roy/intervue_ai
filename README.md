# InterVue AI

An AI-assisted technical interview and assessment platform designed to simulate real-time technical interviews and evaluate candidate performance.

## Features

- User registration and login
- Role-based authentication for candidates and administrators
- Multiple technical interview tracks
- Timed interview sessions
- Voice recognition
- Multiple-face detection
- Fullscreen enforcement
- Tab-switch detection
- Copy, cut, and paste prevention
- Automated answer evaluation
- Coding and theory questions
- Performance analysis
- Strength and weakness identification
- Automated email result delivery
- Admin dashboard
- Detailed interview performance review

## Technology Stack

HTML5 | CSS3 | JavaScript | Python | Flask | Jinja2 | MySQL | Flask-MySQLdb | CodeMirror | Web Speech API | MediaDevices API | Fullscreen API | Werkzeug | python-dotenv

## Interview Tracks

- Python
- Web Development
- SQL & Databases
